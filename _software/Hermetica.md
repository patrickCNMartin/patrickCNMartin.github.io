Hermetica brings version control to wet lab protocols. Protocols are pulled from multiple sources and pinned through a protocol lock file, providing strict version control of what was actually run at the bench.

Wet lab pipelines that chain multiple protocols together are converted into a DAG, which is itself tracked and version controlled. This makes it possible to know exactly which protocol versions, in which order, produced a given data set.
