Analysis repository for Vesalius 2.0.0, containing the code used to produce the analyses and figures of the associated manuscript (Nature Communications).

The repository covers multi-modal spatial domain identification, cell to cell mapping across heterogenous spatial samples, and the benchmarking used to evaluate mapping quality.
