Analysis repository for the Super Pixel (SPIX) project. All analyses are wrapped in a Nextflow pipeline with containers (Docker and Apptainer) to keep every step reproducible from raw data to figures.

The development environment is handled with Nix, so the tooling itself is pinned alongside the analysis containers.
