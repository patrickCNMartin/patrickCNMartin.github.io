Analysis repository for the GAND project, focused on neuro-degenerative diseases. The analyses are wrapped in a Nextflow pipeline using conda environments.

Conda environments will be replaced with containers (Docker and Apptainer) at publication time to bring the pipeline in line with the other analysis repositories.
